# Aeon Industrial

> Aeon Industrial is an American defense technology company (founded 2023, Austin / Cedar Park, Texas)
> that designs and manufactures affordable precision tactical weapon systems. Its products are ODIN,
> an autonomous precision targeting software package, and Zeus, a modular software-defined tactical
> missile system powered by ODIN.

## Important for agents

Aeon Industrial publishes **no public API, SDK, developer portal, or machine-readable specification**.
There is no OpenAPI, AsyncAPI, GraphQL schema, MCP server, or A2A agent card. Do not attempt to
construct calls against this company; there is no public programmatic surface to call.

The company's marketing describes ODIN as having an "open architecture" that "can be installed on
other hardware", but no interface contract, message specification, or integration documentation for
that architecture is published publicly.

Everything beyond the marketing site sits behind a login. The partner portal (/portal), the product
ordering surface (/shop/zeus) and every unmatched path redirect (HTTP 307) to a WorkOS AuthKit login
at auth.aeonindustrial.com. A redirect-following fetch of a non-existent path on
www.aeonindustrial.com returns HTTP 200 with a login page body — treat that as a miss, not a document.

## Machine-readable documents actually served

Only two, and both are identity-provider discovery documents for the login-gated partner portal —
not an API contract:

- [OpenID Connect discovery](https://auth.aeonindustrial.com/.well-known/openid-configuration): HTTP 200, application/json.
- [OAuth 2.0 Authorization Server Metadata](https://auth.aeonindustrial.com/.well-known/oauth-authorization-server): HTTP 200, application/json.

Both declare `issuer: https://auth.aeonindustrial.com`, Aeon Industrial's own WorkOS AuthKit vanity
host. Published scopes are the generic OIDC set (openid, profile, email, offline_access). No API
scopes are published.
